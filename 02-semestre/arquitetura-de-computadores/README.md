# Arquitetura de Computadores

Este diretório reúne os materiais desenvolvidos durante meus estudos na disciplina de Arquitetura de Computadores.

O objetivo é organizar os conteúdos estudados ao longo do semestre e registrar minha evolução na disciplina.

## Conteúdos

Os principais temas estudados serão organizados conforme o andamento das aulas, incluindo assuntos relacionados a:

- Organização e arquitetura de computadores
- Sistemas de numeração
- Representação de dados
- Lógica digital
- Processadores
- Memória
- Dispositivos de entrada e saída
- Funcionamento da CPU

## Organização do diretório

- `anotacoes/`: resumos e anotações pessoais
- `exercicios/`: exercícios desenvolvidos durante os estudos
- `projetos/`: atividades práticas e projetos relacionados à disciplina

## Objetivo

Utilizar este espaço para revisar conceitos, praticar os conteúdos estudados e manter um registro organizado do meu aprendizado em Arquitetura de Computadores.

Este diretório será atualizado ao longo do semestre.
